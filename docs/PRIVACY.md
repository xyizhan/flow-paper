# 数据与隐私

Flow Paper 没有内置账号、统计上报、云同步或自动更新服务。

| 数据 | 保存和发送方式 |
| --- | --- |
| 原 PDF | 保留在原路径；渲染、文本提取在本机进行 |
| 文献元数据、提取文本、阅读位置、批注、笔记、长期对话 | 保存到本机 workspace.json；除 Key 外不加密，受本机文件权限保护 |
| 临时对话 | 仅保存在内存；显式加入笔记或保存到对话才持久化 |
| 模型 API Key | Electron safeStorage 加密保存；明文只在主进程使用 |
| 模型请求 | 主动提问时发送问题、相关历史、选区、检索出的论文页面和图片到配置的服务商 |
| Zotero | 访问本机 127.0.0.1:23119 API；只读元数据与 PDF 路径，不改数据库 |
| Zotero 模型配置 | 用户点击导入时解析指定配置项，不执行配置代码 |
| Codex 登录 | 仅在选用对应协议时复用已有 auth.json；可能按上游逻辑刷新该文件 |

本工具不会主动上传整个 PDF 文件，但可能发送为回答检索到的较长正文。服务商的数据保存、训练使用和计费政策不由 Flow Paper 控制。使用本地 Ollama 可将模型请求也留在本机。

新安装默认使用 `~/Library/Application Support/Flow Paper`；原型升级可能继续使用 `Su Paper`，见安装说明。删除应用不会自动删除工作区。日志和 Issue 中请不要附上工作区、认证文件或未遮盖的密钥。

安装包通过正向文件清单生成，仅包含程序、PDF 引擎与资源、必要元数据和许可证。公开截图使用生成的测试数据。`scripts/audit-release.py` 扫描发布文件，但自动扫描不能证明不存在所有隐私或安全问题。
