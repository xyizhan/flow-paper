# 使用与配置

## 打开与整理

点击“＋ PDF”或拖入 PDF，原文件保留在原位置。菜单栏“打开方式 → Flow Paper”也可打开 PDF。文献栏可搜索标题、作者，筛选分类，拖动边界调整宽度。

连接 Zotero 时保持 Zotero 运行，并在其设置 → 高级中允许其他应用与本机通信，再点“Zotero ↻”。当前只读个人文献库。附件必须已下载到本机；关闭 Zotero 后，之前解析到本地路径的文件仍可阅读。没有 Paperlib 桥接、群组库或批注双向同步。

## 配置模型

点齿轮选择协议并填写服务商提供的 API 地址、模型 ID 和 Key。支持 OpenAI Compatible、OpenAI Responses、Anthropic Messages、Gemini Native、Ollama Native 和上游 Codex Responses。具体模型和账号能力由服务商决定；图片问答需要视觉能力。Ollama 本地服务可以不填 Key。

“从 Zotero 导入模型”只读取 LLM for Zotero 的模型配置；不执行 prefs.js。导入后加密 Key 保存在主进程，界面只显示是否已保存。留空表示保留现有 Key；“清除已保存的 Key”会删除本工具保存的 Key。

Codex 选项复用上游认证实现，要求已有本机登录文件，路径为 `$CODEX_HOME/auth.json` 或 `~/.codex/auth.json`。需要刷新时，上游会更新该文件。不要把该文件放进项目目录或公开仓库。

## 临时提问

选中文字后点“翻译 / 解释 / 提问”。点“截图”后在论文中框选图片，同样进入临时框。可以继续追问、拖动浮框，Esc 或点击外部关闭。默认不写入持久化对话；主动选择“保存到对话”或“加入笔记”才保存。服务商仍可能按自己的政策保留已发送数据。

## 长期对话与笔记

顶部“对话”（⌘⇧J）打开上次使用的面板。右上角按钮切换停靠和弹出。拖动六点手柄可从侧栏拖出，或在阅读器右边缘预览后松手吸附；Esc 取消拖动。系统标题栏用于普通窗口移动。侧栏边界可拖动，键盘聚焦边界后用方向键调整宽度。

切换模式保留同一个页面、草稿、附件和生成中的回答。收起面板会停止生成并保留已生成的长期内容。临时问答不进入此历史。

勾选论文后选择“勾选的论文”，或者先索引再选择“已索引文献库”。检索受模型上下文预算限制，回答下方会标明提供了哪些页面、是否部分检索。点击页码回原文。检索命中不代表模型已经通读所有文献。

AI 回答可加入 Markdown 笔记，支持编辑、预览和导出。PDF 高亮、批注由原阅读器提供，新批注保存到 Flow Paper 工作区，需要带走时使用 PDF 导出功能。
